# Reviewed Phone staging

Only normalized candidate packets that passed structural/provenance checks belong here.

Staging is still not public data. Promotion to `data/phone/v1/` is explicit and reviewed.

Priority scope:
- low-cost long-term SMS/OTP number routes;
- high-value data SIM/eSIM routes.

Ordinary high-cost monthly plans are not expansion targets unless they solve a clearly distinct job that cheaper routes cannot.
