# Fortress haha SIM retention resolution — 2026-09-25

Status: **RETENTION RULE RESOLVED / ROUTE STILL HOLD**

## Scope

Resolve the narrow conflict discovered by the Phone watcher review: community reports described `HKD 10` as the annual haha SIM keep-alive top-up, while 3HK's generic prepaid online-recharge page currently states a `HKD 100` minimum and says only `HKD 100+` recharges extend card validity.

This document resolves the current keep-alive rule only. It does not admit haha SIM to production and does not resolve the route's separate activation/registration/onboarding-confidence blockers.

## Current first-party result

Fortress's current haha SIM FAQ is product-specific and states:

- after activation, haha SIM is valid for **365 days**;
- a **HKD 10 or greater value top-up** automatically extends SIM validity by **365 days**;
- buying a data package does **not** extend validity;
- the current supported balance top-up workflow is through the **haha TRAVEL App** rather than another website/app;
- if a haha SIM expires, Fortress says a reactivation request may be attempted within **14 days**; if approved, real-name registration must be completed again. After 14 days, number reactivation is not offered.

Current public Fortress FAQ:
- https://www.fortress.com.hk/zh-cn/services?category=Order
- https://www.fortress.com.hk/en/services/services?category=Order

The current haha TRAVEL app listing also describes top-up and account management as app functions:
- https://play.google.com/store/apps/details?id=com.fortress.sim
- https://apps.apple.com/hk/app/haha-travel-by-fortress/id1482719988

## Why the 3HK `HKD 100` page does not override the haha rule

3HK's generic prepaid online-recharge page currently says:

- minimum online top-up: **HKD 100** per transaction;
- card expiry extension applies to **HKD 100+** recharge.

Source:
- https://www.three.com.hk/3Care/eng/prepay/payonline1.jsp

That page is a generic 3HK prepaid recharge surface. Fortress's current product-specific haha SIM FAQ explicitly gives a different validity rule (`HKD 10+` → `+365 days`) and directs haha balance top-ups to the haha TRAVEL App. Therefore the generic 3HK recharge-page floor must not be used as the current haha SIM keep-alive rule.

- **keep-alive amount:** `HKD 10+`;

- **current official recharge path to publish if needed:** **haha TRAVEL App**;
