Cursor included usage resets with your billing cycle. Individual plans reset monthly. Team members reset together based on the team billing cycle. Unused included usage does not roll over, and Cursor shows your account’s exact reset date in the Spending tab.

When does Cursor usage reset?

Cursor’s current documentation says included usage resets monthly with your billing cycle. It is not a universal first-of-the-month reset. Your account’s reset date is shown in the Spending tab.

Does unused Cursor usage roll over?

Cursor says unused included usage does not roll over to the next billing cycle. If you have a meaningful amount left near the reset date, the pace calculation above can help you decide how quickly you can use the remainder without exhausting it too early.

Why enter the exact reset shown in Cursor?

Billing systems can have account-specific timestamps, plan changes and edge cases. Rather than invent a universal reset hour, this calculator lets Cursor remain the source of truth and turns the date it shows you into a persistent local countdown.

How to find your exact Cursor reset date

  1. Open the Cursor dashboard for the account or team you actually use.
  2. Open Spending and locate the reset date shown for the current billing cycle.
  3. Enter that date above. This calculator stores it locally and turns it into a live countdown and daily pacing estimate.

Using the date from your own Cursor account is more reliable than assuming everyone resets on the first day of the month. Cursor’s billing cycle begins from the subscription date for individual plans, while teams use the team billing cycle.

Cursor usage limits now use separate monthly pools

Cursor currently documents two included usage pools on supported plans: Cursor Models and Other Models. Both reset with the monthly billing cycle. This matters because one pool can be depleted faster than the other depending on which models you use.

The calculator above intentionally asks for a percentage instead of hard-coding a request count or dollar amount. Cursor can change plan allowances and model pricing, while your account dashboard remains the source of truth for the balance you actually have.

What happens when Cursor included usage runs out?

If included usage is exhausted, what happens next depends on your plan and settings. Cursor documents optional on-demand usage for supported plans; if it is enabled, additional requests can be billed at the applicable rates. If on-demand usage is disabled or a spend limit is reached, AI usage can stop until the next billing cycle or until settings change.

That is why the pacing estimate is useful: it converts “percent left” and “days until reset” into a simple daily budget without pretending to know private account data.

Individual vs. Teams reset behavior

For individual subscriptions, Cursor says the billing cycle starts on the subscription date and renews monthly or yearly depending on the plan; included usage resets monthly. For Teams, members’ usage resets together according to the team billing cycle. Adding or removing a member does not create a separate personal reset schedule for that member.

Frequently asked questions

Does Cursor usage reset daily?

Current Cursor documentation says included usage resets monthly with the billing cycle, not daily.

When is my Cursor reset date?

Open Cursor’s Spending tab. Cursor says the reset date for your account is shown there.

Does unused Cursor usage carry over?

No. Cursor says unused included usage does not roll over to the next billing cycle.

Can this calculator see my Cursor usage?

No. It only uses the reset date and optional usage percentage you enter locally.

Does Cursor Pro usage reset on the first of the month?

Not necessarily. Cursor ties included usage to the billing cycle, so an individual account can reset on its own monthly billing date rather than on the first day of the calendar month.

Do Cursor Models and Other Models reset at different times?

Cursor currently says both usage pools reset with the monthly billing cycle. They are tracked separately, but the reset cycle is the same.

What happens if I hit a Cursor spend limit?

Cursor says usage can stop when a configured spend limit is reached. Usage resumes when the next billing cycle starts, or earlier if an authorized user changes the limit or usage settings.
