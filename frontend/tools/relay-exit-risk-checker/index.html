How to read this score

The community exit-risk percentage is simply the average of user predictions for the entered relay domain. It is not a probability model trained on verified shutdowns yet. The model-dilution number is also community sentiment, not an API test result. As the historical dataset grows, verified operating events can be added as a separate evidence layer without rewriting past votes.

Why prepaid exposure matters

A relay can be useful today and still be a poor place to park a large balance. The calculator converts your balance into days of normal usage. A seven-day balance is easier to replace than a sixty-day balance if the service changes, pauses, or disappears.

Privacy and abuse limits

This page does not ask for your relay API key. Community voting stores the relay hostname, two 0–100 scores, a random browser voter ID and timestamps. Public comments are intentionally excluded from this first version to reduce spam and unverified allegations.

Frequently asked questions

Does a high score prove a relay will disappear?

No. It is a community forecast. Treat it as a prompt to limit prepaid exposure and verify evidence, not as proof of wrongdoing.

Does this tool test whether a relay is watering down or swapping models?

No. The model-dilution percentage is community sentiment. Use one of the linked specialist verification tools for an actual model/protocol test.

Can I change my vote?

Yes. Voting again from the same browser for the same relay updates that browser's previous vote.

What should I enter as the relay site?

Enter the public hostname or URL you use to identify the relay. The community aggregate is grouped by hostname.
