Current policy source

Current GitHub usage-based billing resets included AI Credits at 00:00 UTC on the first day of each calendar month. Unused included credits do not roll over. GitHub currently lists 1,500 monthly AI Credits for Copilot Pro, 7,000 for Pro+, and 20,000 for Max. Source: GitHub Docs ↗

Why the reset date can surprise new subscribers

GitHub separates the subscription billing date from the included AI Credits reset. The included allowance refreshes on the first day of the calendar month, so someone who subscribes late in a month can see a reset only days later while their next subscription charge is still weeks away.

Why a burn-rate calculator matters

GitHub AI Credits are usage-based: heavier models and longer agent sessions can consume credits faster than short interactions. The calculator compares your remaining balance with the exact time left in the calendar month instead of assuming every day costs the same.

What happens to unused credits?

GitHub states that unused included AI Credits are forfeited at the monthly reset. Additional paid usage is separate from the included allowance. One AI Credit is currently priced at $0.01 for additional usage.

Frequently asked questions

When do GitHub Copilot AI Credits reset?

At 00:00 UTC on the first day of each calendar month.

Does the reset follow my Copilot billing date?

No. GitHub documents the included allowance reset as a fixed calendar-month reset, independent of your subscription billing date.

Do unused included AI Credits roll over?

No. Unused included credits are forfeited when the monthly allowance resets.

How much is one GitHub AI Credit worth?

GitHub currently prices additional usage at $0.01 per AI Credit.
