Quick answer: when do Claude usage limits reset?

Claude has more than one usage window. Current Anthropic guidance documents a five-hour session-based limit for supported plans and separate weekly limits. Weekly reset timing is account-specific, so use the timestamp shown by Claude rather than assuming a universal weekday or hour.

Session reset vs weekly reset

Anthropic documents separate usage windows. The session-based window can reset every five hours on supported Claude plans. Weekly limits are separate and reset at a fixed time assigned to the account. A new five-hour session therefore does not by itself mean the weekly allowance has replenished.

Where to find your weekly Claude reset time

Anthropic says paid users can open Settings > Usage to see progress for the current five-hour session and weekly limits, including the next weekly reset. Enter that timestamp above instead of guessing a universal reset day. Claude usage-limit guidance ↗

Does /limit-reset consume or reset weekly quota?

Anthropic’s public documentation checked for this page does not currently document /limit-reset or state that it grants additional weekly allowance. This calculator therefore does not treat the command as a weekly quota reset. Keep the weekly countdown anchored to the reset shown in Settings > Usage until Anthropic publishes a rule.

Claude Code plan usage vs API-key billing

Claude Code usage depends on how you sign in. Anthropic documents plan or seat usage as quota-limited, while API-key usage is pay-as-you-go rather than the same hard plan reset. This page is for users tracking the reset times shown by a Claude plan or seat. Claude Code models, usage, and limits ↗

Why this calculator asks for Claude’s displayed time

Weekly reset time is account-specific, and provider rules can change. Using the timestamp Claude shows you avoids inventing a fixed weekday, hour, request count or weekly allowance.

Frequently asked questions

How often does Claude usage reset?

Anthropic currently documents a five-hour session-based usage window for supported Claude plans, plus separate weekly limits on paid plans.

When does my Claude weekly limit reset?

The weekly reset is assigned to your account. Check Settings > Usage for the next reset time and enter it in the calculator.

Does a five-hour session reset also reset my weekly limit?

No. Anthropic documents session and weekly limits as separate usage windows.

Does /limit-reset reset or avoid the weekly quota?

Anthropic public documentation checked for this page does not currently document /limit-reset or say that it replenishes weekly quota, so this tool does not assume that it does.

Does this tool connect to my Claude account?

No. The timestamps you enter are stored only in your browser.

Does Claude Code API-key usage use this same reset?

Not in the same way. Anthropic documents API-key usage as pay-as-you-go, while plan or seat usage can have usage windows and reset times.
